# INKFORGE — AI Cover Generation Engine & Art Direction Pipeline

## Design Philosophy

Traditional automated cover generators often suffer from two major flaws:
1. **Baked-in Gibberish Typography**: Direct text rendering from diffusion models frequently hallucinates distorted letterforms, unreadable titles, and misspelled author names.
2. **Fragile Overpromises**: Crashing or returning fake mockups when an external API key or model quota is exhausted.

**INKFORGE resolves both flaws with an uncompromising editorial approach:**
- **Crisp Composited Typography**: The generative model is instructed to output purely background artwork and textures with strategic negative space. All book titles, subtitles, colophons, and author names are rendered via crisp HTML/CSS using Charter serif and Editorial Mono typography.
- **Truthful Multi-Tier Art Engine**: If a Gemini API key (`GEMINI_API_KEY`) is provided, INKFORGE utilizes advanced multimodal image generation. If absent, the system **honestly discloses** the provider status and seamlessly switches to the built-in **Curated Editorial Art Engine** (generating mathematical canvas/SVG artwork tailored to genre and mood).

## 2. Prompt Engineering Pipeline

The prompt compilation process in [`prompt-builder.ts`](file:///Users/kingpin/Documents/Vibecoded%20projects/inkforge/src/lib/cover-generator/prompt-builder.ts) transforms book metadata into high-fidelity generative prompts:

### Negative Space Allocation
Diffusion models naturally attempt to place focal points in the center. INKFORGE explicitly directs composition:
> *"Leave clean negative space in the upper third for editorial typography. High contrast, museum-quality texture."*

### Strict Negative Prompts
To eliminate distorted text generation:
> *"NO text, NO letters, NO words, NO typography, NO watermarks, NO blurry edges, NO low resolution, NO generic digital 3D rendering."*

### Directional Stylization
- **Editorial**: Constructivist geometric composition, architectural cross-sections, risograph grain, duotone color palettes.
- **Cinematic**: Chiaroscuro lighting, deep shadows, atmospheric mist, medium format film photography grain.
- **Experimental**: Deconstructed typographic forms, procedural generative gradients, abstract fluid kinetics.
- **Classic**: Hand-marbled endpapers, gold-leaf flecks, blind debossed linen textures, vintage copperplate etching.

## 3. Typographic Compositing Layer

Artwork generated by the pipeline is treated strictly as the **underlay**. The cover presentation is assembled via three stacked layers:

```
┌────────────────────────────────────────────────────────┐
│ Layer 3: Foil & Type Overlay (Crisp HTML / CSS)       │
│ - Title (Charter serif / Editorial font)               │
│ - Subtitle (Italicized secondary line)                 │
│ - Author Inscription & Publisher Colophon              │
├────────────────────────────────────────────────────────┤
│ Layer 2: Tactile Materials & Finish                    │
│ - Linen / Buckram cloth weave SVG texture filter       │
│ - Blind-debossed framing borders & corner fillets      │
│ - Directional lighting sheen & paper shadow            │
├────────────────────────────────────────────────────────┤
│ Layer 1: Art Underlay                                  │
│ - High-resolution generative artwork / SVG canvas      │
└────────────────────────────────────────────────────────┘
```

Because the typography is rendered entirely in CSS:
- Authors can edit titles or fix typos without re-generating art.
- Letterforms remain tack-sharp at any zoom level, retina display, or print resolution.
- Font sizing dynamically scales using fluid typography formulas.

---

## 4. Cover Versioning & Immutability

Authors frequently iterate on visual direction. INKFORGE enforces **zero destructive overwriting**:

1. Every generation creates a unique `CoverVersion` with timestamp, palette tokens, prompt copy, and provider attribution.
2. New versions are appended to `book.covers[]`.
3. The author can freely audition, switch between, or restore historical covers via the **Cover Version History** studio panel without losing previous iterations.
4. Custom uploaded art or alternative direction explorations are preserved alongside initial editions.
