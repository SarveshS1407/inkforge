# INKFORGE — Product & Engineering Roadmap

## Milestone 1: Foundations & The Writer's Studio (Current)
- [x] Project initialization & architecture specification
- [ ] Core repository structure and build toolchain (Next.js 15, TypeScript, Tailwind)
- [ ] Editorial design system & typography setup
- [ ] Tiptap block editor engine with custom blocks (callouts, quotes, code, image embeds)
- [ ] Local auto-save, draft management, and content serialization (JSON AST & HTML)
- [ ] Clean public reader frontend with responsive reading mode and dark/light theme toggle

## Milestone 2: Persistence, Publishing & Workflows
- [ ] Database schema (PostgreSQL with Prisma / Drizzle)
- [ ] Content states: Draft, In Review, Scheduled, Published
- [ ] Scheduled publishing runner / cron trigger
- [ ] Post revisions & history tracking
- [ ] Tagging, categories, search, and SEO (OpenGraph, sitemap.xml, RSS)

## Milestone 3: Multi-Author & Editorial Roles
- [ ] User authentication (OAuth & Magic Links)
- [ ] Multi-author publication entities
- [ ] Role-based access control (Owner, Editor, Author, Contributor)
- [ ] Editorial review workflows (submission, feedback, approval)

## Milestone 4: Community, Distribution & Growth
- [ ] Reader engagement (comments, claps/likes, bookmarks)
- [ ] Newsletter dispatch and subscriber management
- [ ] Reader analytics & metrics dashboard
- [ ] Custom domain support for publications
